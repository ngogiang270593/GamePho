# Forest keeper automatic action sprites

Generated with the built-in `image_gen` tool, using `turnaround-v2.png` as the identity and outfit reference.

Source images: `client/assets/characters/forest-keeper/walk-{male,female}-v1.png` and `{turn,run,jump}-v1.png`. Packed runtime atlases: `walk-atlas-v1.webp`, `turn-atlas-v1.webp`, `run-atlas-v1.webp`, `jump-atlas-v1.webp` in the same directory. Full PNG atlases are retained alongside them.

Each runtime atlas has four columns and four rows, with eight male frames followed by eight female frames. `node scripts/pack-forest-animation.mjs` packages the original figure pixels into equal cells and a shared ground baseline.

The creator automatically loops idle → walk → turn → run → jump. It pauses when hidden and uses a still pose with reduced motion.

These are rendered sprite animations, not a real-time 3D mesh or physics simulation.

Self-contained animation preview: `output/forest-animation/preview.html`, exported with `node scripts/export-forest-animation-preview.mjs`. Browser screenshots and verification: `output/forest-outfit/browser-report.json` and `screen-*-{walk,turn,run,jump}.png`. The automatic cycle is verified for both genders and a 393 px mobile viewport.
